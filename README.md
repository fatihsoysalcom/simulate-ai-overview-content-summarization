# Simulate AI Overview Content Summarization

This example demonstrates the core concept behind Google's AI Overviews. It simulates how an AI might extract and summarize relevant information from a block of text based on a user query. By identifying sentences containing keywords from the query, it produces a simplified 'AI Overview' to show how direct answers can be generated without clicking through links.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
